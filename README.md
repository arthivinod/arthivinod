### 🚀 Featured build: Resolved

**An AI agent that fights back.**

Companies increasingly use AI to deflect and deny customer complaints at scale. Resolved flips that asymmetry — drop in a photo, screenshot, or forwarded email of a bad order, delay, or overcharge, and it:

1. **Extracts the facts** — vendor, order ID, amount, issue — straight from your evidence
2. **Picks a strategy** — channel, tone, and the exact legal clause to cite, tailored per vendor
3. **Drafts a firm, law-cited complaint** in seconds
4. **Auto-escalates** across channels — vendor → public post → grievance officer → national helpline → consumer court — until you're paid

Built solo end-to-end: product thinking, design system, working React prototype, and real Claude API integration for extraction + drafting.
